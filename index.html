Desktop app concept

Turn a live event into one clear action.

Minu Streamer is an interaction concept for live creators. A gift can show an alert, a follow can update a counter, and a chat command can change a scene. This public page documents the idea and links to a working browser prototype.

Product idea

Keep the rule readable.

The main constraint is that a creator should understand a rule without opening a separate settings page. I treated each trigger as a short sentence: event, condition, action. The browser prototype is there to test that interaction before adding a desktop shell or live platform API.

  1. 01Select an eventGift, follow, share, like goal or chat command.
  2. 02Set the conditionFor example a gift name, command text or threshold.
  3. 03Choose the actionAlert, counter update, sound, animation or scene change.
  4. 04Run a local testCheck the rule before connecting it to a live event source.
