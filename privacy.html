Minu Streamer Privacy Policy

Minu Streamer uses TikTok Login Kit only to let users sign in with TikTok and display their basic TikTok profile information inside the desktop application.

The application may access basic profile information such as display name and profile photo after the user authorizes access through TikTok.

Minu Streamer stores configuration data locally on the user's computer, including triggers, commands, keys, and optional profile display information.

Minu Streamer does not sell personal data and does not share TikTok profile information with third parties.

Users can remove their connected TikTok account or delete the local application data at any time.

Minu Streamer is not affiliated with, endorsed by, or sponsored by TikTok.
