# Minu Streamer

Public landing page for a desktop app concept aimed at live creators.

The product idea is simple: map a live event to an action. A gift can show an alert, a follow can update a counter, and a chat command can trigger a scene change.

Live site: https://jean-nnrr.github.io/minu-streamer-site/

Interactive UI prototype: https://jean-nnrr.github.io/minu-streamer-pages/

## What is in this repo

- responsive product landing page
- hand-built dashboard mockup
- terms and privacy pages
- product copy written around the actual interaction model

The site is static. It explains the concept and links to the interactive prototype; it does not claim to process TikTok Live events on its own.

Built with plain HTML and CSS so the page stays easy to inspect and deploy.
